# Esto es un extractor de protocolos de WhatsApp básico diseñado para un propósito educativo, basado en el extractor original de Baileys, los principales créditos directamente a Baileys.

Usage:

1. CD + Route
(/storage/emulated/0/WhatsApp/) //Recommended

2. node proto.js


Into node_modules están todas las dependencias ya listas, cualquier error de entorno o similar borra las dependencias que ya tiene y ejecuta nuevamente "npm install"
